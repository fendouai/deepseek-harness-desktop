# @deepseek-ai/dsh-client-ui-avatar

[English](README.md) | 中文

浏览器 Avatar 插件占用可叠加的 `shell.overlay` 插槽。它在 Harness 工作区上方显示四个内置原创角色之一，或用户选择的一张 PNG、JPEG、WebP 或 GIF 图片，并根据当前会话摘要推导 `idle`、`working` 和 `complete` 展示状态。所选预设、导入图片、显示开关和尺寸保存在浏览器存储中；源文件限制为 1.25 MB，避免单张图片耗尽常规存储配额。

单图渲染器提供呼吸、工作与完成动画，但不宣称具备骨骼动画或精确口型。选择 Mina、Yuna、Rin 或 Sora 会替换导入图片，选择新的本地图片会替换当前预设。插件不使用 Tauri IPC，不读取任意文件路径，也不增加模型可见输入。

## 模型体验

无，因为 Avatar 状态只是现有会话列表事实的浏览器投影，不贡献提示词、消息、工具或会话事件。

#### KV Cache 影响

无。启用、隐藏、缩放或更换 Avatar 图片不会改变模型输入。

## 已知限制与延期工作

- 平面图片不能提供 Live2D 骨骼、VRM 动作、音素口型，也不能显示在应用窗口之外的原生透明桌面层中。
- 当前活动投影只使用粗粒度会话摘要字段。工具专属动作需要独立的持久 Avatar 状态投影，而不是从文本记录中在客户端推断。
- 浏览器存储适合一张小图片。角色包与大型模型资源需要由 sidecar 管理的资源存储。
